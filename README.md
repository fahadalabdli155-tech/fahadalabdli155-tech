## About Me

I'm **Fahad**, a third-year **Electrical Engineering** student at **King Abdulaziz University** in Jeddah, with distinction-level grades.

I build real web and mobile products using **AI-assisted development** with Claude Code. My work focuses on **Arabic-first, bilingual products** for real users, organizations, and clients: task managers, program platforms, event systems, and AI-powered store tools.
